# 🚀 Telegram Auto-Poster System

Автоматизована система публікації рекламних оголошень у цільові групи та канали Telegram з індивідуальними інтервалами, хмарною базою даних Supabase, десктопною веб-панеллю в стилі Telegram та мобільним адмін-ботом.

---

## 🌟 Основні можливості

1. **Індивідуальні таймери для кожного чату:** 
   * 1 година (60 хв), 1 доба (24 год), 3 дні (72 год) або будь-який інший інтервал.
2. **Анти-фрод та безпека (Anti-Ban):**
   * Автоматичне виявлення `Slowmode` у чатах та адаптивне перенесення відправки.
   * `FloodWait` захист — очікування точного часу без ризику блокування.
   * Рандомізація затримок (human-like jitter) між чатами.
3. **Хмарна синхронізація (Supabase):**
   * Легкий перенос з ПК на VPS за 1 хвилину без втрати списку чатів та історії.
4. **Подвійний інтерфейс:**
   * 💻 **Desktop Web Dashboard:** Стилізований під автентичний Telegram Desktop Dark Mode з живим прев'ю повідомлення та масовим імпортом 50 чатів.
   * 📱 **Mobile Telegram Bot:** Інлайн-кнопки у вашому смартфоні для миттєвої паузи/запуску та моніторингу статусу на ходу.

---

## 📋 Покроковий запуск

### 1. Створення таблиць у Supabase
1. Відкрийте ваш проект у [Supabase Dashboard](https://supabase.com/dashboard/project/lwkfsdyoynooympbidyr).
2. Перейдіть у розділ **SQL Editor** (зліва в меню).
3. Скопіюйте вміст файлу `database/schema.sql`, вставте його в редактор і натисніть **Run**.

### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3. Одноразова авторизація вашого Telegram акаунту
Запустіть інтерактивний скрипт авторизації:
```bash
python auth.py
```
* Введіть ваш номер телефону та код із Telegram (а також пароль 2FA, якщо він встановлений).
* Буде створено файл сесії `poster_session.session`.

### 4. Запуск комплексу
```bash
python main.py
```

* **Панель на ПК:** відкрийте у браузері [http://127.0.0.1:8000](http://127.0.0.1:8000)
* **Бот на телефоні:** відкрийте вашого бота в Telegram та надішліть йому `/start`.
